Current capabilities:
- Estimated PV output for each forecast hour (kW).
- Total estimated energy for the selected day (kWh).
- Peak estimated production and its forecast hour.
- Hourly production profile for selected roof areas.
- Live shading preview for the selected sun date/time.
- Annual sun-access simulation.
- Monthly and annual PV-production estimates, including PVGIS data when available.
What we cannot monitor yet:
- Actual inverter production in real time.
- Historical measured production.
- Panel, inverter, battery, grid-import/export, or consumption data.
- Alerts for faults or underperformance.
- A dedicated “production now” KPI — the current-hour estimate is only available as a point on the forecast chart.
So the app currently provides solar estimates and simulations, not live system monitoring.
